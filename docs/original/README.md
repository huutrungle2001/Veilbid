# Original Source Inputs

Files in this directory preserve inputs used to prepare the canonical VeilBid
documents. They are not automatically official or correct.

## Contents

- `user-provided-challenge-brief.md`: verbatim user-provided challenge brief.
- `user-provided-challenge-brief-normalized.md`: formatting-normalized extract
  for easier reading; never use it to override the verbatim capture.
- `discord-context-extract.md`: relevant excerpts transcribed from a local
  Discord export supplied by the user.

## Source handling

Canonical project decisions belong in:

- `../competition-summary.md`
- `../requirements.md`
- `../judging-criteria.md`
- `../important-notes.md`

If an original input conflicts with an official source, use the official source
and record the conflict. Do not quote usernames, wallet addresses, or unrelated
conversation in public judge-facing documents.

The full raw `chat.txt` is intentionally excluded from the repository. It
contains unrelated participant messages and identifiers. Only relevant excerpts
with source caveats are preserved here.
